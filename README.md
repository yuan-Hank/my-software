AI百团大战海报生成器 · 功能简述
一款面向社团招新场景的桌面软件：填好社团信息，AI 生成背景图，再自动排版文字，几分钟做出一张招新海报。
一、AI 出图（核心）

五家服务商任选 ：智谱、阿里通义、OpenAI、硅基流动，以及自定义接口；API Key 本地加密存储
双通道自动分流 ：普通文生图走图片接口，gemini、nano-banana、gpt-4o-image 等自动改走对话接口，用户无需关心
角色参考图 ：可上传人物参考图（自动旋正、压缩到几百 KB 再发送，大图也不失败）
智能文案 ：一键生成口号；把一句话自动拆成「时间 / 地点」并填充表单
生成前确认弹窗 、生成中可随时 取消
离线降级 ：没配 Key 或请求失败时，自动用 4 套内置渐变光斑模板出图，软件永远可用
二、布局编辑（生成后可自由调整）
拖拽移动 文字块，靠近边缘/居中时自动吸附，显示参考线
4 套一键版式 ：底部信息条、左对齐、居中大标题、对角排版
水平居中 / 底部对齐；方向键微调（Shift 加速）
字号调节 ：直接输入像素值或 A−/A+ 步进
字体 / 颜色 切换（思源黑体、雅黑、黑体、宋体）
自动换行 ：长文字按设定宽度折行，不再跑出画面
双击文字块直接改字 ，也可删除任意块
＋ 添加自定义文字块 （如「扫码报名」「QQ 群号」）
撤销 / 重做 ：按钮或 Ctrl+Z / Ctrl+Y，覆盖以上全部编辑操作
三、成品与管理
保存到输出文件夹、另存为、一键 复制到剪贴板 （可直接粘贴到 QQ/微信）
「我的海报」历史 ：自动保存缩略图与文案，可随时找回、另存
